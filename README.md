# React Native E-commerce App

A fully responsive, and featured e-commerce mobile application built with bare react-native for end user for seamless shopping experience. In which user can place thier order easily and check order status that make this app user friendly. 

## About the project 
this app alows user to browse and search products, order and easily check status of thier order history and easy payment option. Completely, user friendly and easy to use.

## Teck Stack 

- **Bare react native** - for mobile UI development
- **Node.js/Express** - for backend/api
